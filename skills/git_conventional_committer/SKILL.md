### DOMAIN SKILL: CONVENTIONAL GIT WORKFLOWS
1. Structure commit messages as <type>(<scope>): <summary> (e.g. 'feat(mcp): add dynamic tool registration').
2. Keep commits atomic and self-contained.
3. Never commit node_modules, build artifacts, or secret keys (.env).
4. Summarize changes clearly in bullet points when preparing pull requests.
